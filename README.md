# Music App

A full-stack music application for browsing songs, artists and albums.

Built as a coursework project with a React frontend and a Node.js/Express backend connected to a MySQL database.

**Features:**
- Browse and view songs, artists and albums
- REST API backend with dedicated routes/controllers for songs, artists and albums
- Frontend built with React, communicating with the backend via API calls

**Built with:** React, Node.js, Express, MySQL

**Note:** database credentials are not included (see `backend/.env.example` for the required format) — copy it to a `.env` file with your own database details to run this locally.
